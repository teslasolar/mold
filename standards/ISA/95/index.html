🔗 ISA-95

Enterprise-Control System Integration | IEC/ISO 62264

Overview

ISA-95 is the international standard for integrating enterprise and control systems. Based on the Purdue Reference Model, it defines 5 hierarchy levels and provides models for equipment, personnel, materials, and operations management.
