🖥️ ISA-101

Human Machine Interfaces for Process Automation | IEC 63303

Overview

ISA-101 provides a lifecycle approach for designing, implementing, operating, and maintaining HMIs. Focus areas: human-centered design, situational awareness, display hierarchy, alarm management, and continuous improvement.

📺 Display Hierarchy (4 Levels)

Organized information delivery for situational awareness

Level 1 — Enterprise/Area Overview
High-level KPIs, plant-wide status, navigation hub. Used by supervisors monitoring multiple processes.
Level 2 — Unit/Process Overview
Process flow, key parameters, abnormal situation detection. Primary operator working display.
Level 3 — Unit Detail/Control
Detailed equipment status, setpoints, trends, control actions. Faceplates and popups.
Level 4 — Diagnostic/Support
Maintenance screens, configuration, troubleshooting, raw I/O. Engineering access.

🎯 Core Design Principles

  • Situational Awareness — What's happening, why, what's next
  • Relevance over Detail — Show only what operators need
  • Abnormal = Obvious — Problems stand out immediately
  • Consistent Navigation — Predictable screen patterns
  • Minimal Cognitive Load — Reduce mental effort
  • Gray Background — Reserve color for meaning
  • Analog over Digital — Bars/trends over numbers
