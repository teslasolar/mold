🏷️ Tags & UDTs

Token-efficient tag definitions based on ISA standards

📄 File Format

Custom .udt and .tag formats optimized for <250 tokens per file

.udt (User Defined Type)

#UDT:S88_Valve:1.0
@base:S88_CM
$std:S88
%cat:Valve
---
opn_cmd:B:0:Open command
cls_cmd:B:0:Close command
opn_fb:B:0:Open feedback
pos:R:0:Position %

.tag (Instance)

#TAG:XV001:S88_Valve
@path:Main/Area1/Unit1
$inst:Inlet_Valve
%id:A001
---
name:Inlet Isolation
mode:2

📝 Type Codes

B = BOOL
I = INT
D = DINT
R = REAL
S = STRING
T = TIME
DT = DATE_TIME
A[] = Array
U:Name = UDT ref
E:Name = Enum

📁 Directory Structure

tags/
├── udt/
│   ├── s88/          # ISA-88 UDTs (CM, EM, Unit, Valve, Motor...)
│   ├── s95/          # ISA-95 UDTs (Site, Area, WorkCenter...)
│   ├── hmi/          # ISA-101 UDTs (Screen, Faceplate, Alarm...)
│   └── mold/         # Project UDTs (Assessment, Zone, Schedule)
├── instance/
│   ├── equipment/    # Equipment tags (XV001, PMP001, TT001...)
│   ├── process/      # Process tags
│   ├── hmi/          # HMI tags
│   └── mold/         # Mold assessment tags
├── template/         # Reusable templates
└── FORMAT.md         # Format specification
